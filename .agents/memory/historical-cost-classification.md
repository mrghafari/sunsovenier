---
name: Historical cost classification
description: Do not confuse immutable journal amounts with historical fleet/account configuration.
---

Retrospective shipping/fleet analytics must disclose when they classify posted
amounts using current posting mappings and the current fleet center. Do not
present that classification as the configuration in effect on the posting date.

**Why:** Journal immutability protects the amounts, but not the interpretation
produced by subsequently edited account mappings or fleet settings. A plausible
historical configuration inferred from today's settings would be unsupported.

**How to apply:** Keep current-basis disclosures in the UI and exports until
trustworthy dated configuration snapshots exist. Preserve recorded journal
amounts and reversal signs; do not recalculate old absorption from today's rates.
